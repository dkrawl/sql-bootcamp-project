## Fact card tabela

Jedan red u tabeli fact_card predstavlja jedan dogadjaj kartona u utakmici.
Tabela sadrzi kljuceve date_key, team_id, player_id i referee_id koji povezuju cinjenice sa tabelama dim_date, dim_team, dim_player i dim_referee.
Kartoni imaju svoju tabelu cinjenica zato sto mozemo analizirati kartone kao dogadjaje po razlicitim kriterijumima: po igracu, po klubu, po sudiji..
